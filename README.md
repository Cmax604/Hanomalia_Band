# HANOMALIA

Site statique en français conçu d’après le moodboard Canva HANOMALIA : noir #050505, blanc #F4F1EA, rouge #A71A1F, beige #D3C3A7. Polices : League Spartan, Pirata One, Permanent Marker et Special Elite (Google Fonts).

## Publication

Déposer le contenu de ce dossier dans le dépôt GitHub du groupe, sur `main`. Dans Settings → Pages, choisir GitHub Actions comme source. Le workflow `.github/workflows/pages.yml` publie uniquement les fichiers publics.

Documentation : https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## Contenu

Modifier `index.html` pour les textes et liens, `styles.css` pour la présentation. Les liens de contact proviennent du dossier de presse Canva. Les annonces de concerts renvoient au compte Instagram officiel ; aucune date ni sortie non confirmée n’est inventée.

Les images de `assets/` sont les aperçus fournis par Canva du moodboard existant. Pour une qualité optimale, remplacer ces fichiers par les originaux haute résolution avec les mêmes noms. Le logo n’a pas été redessiné.

Le site n’utilise pas de traceur, de formulaire serveur ni de dépendance à installer. Les polices sont chargées depuis Google Fonts ; les liens musique ouvrent Linktree.
